Позначайте потрібні рядки, переходьте до функцій, форматуйте, коментуйте та
згортайте код, не виходячи з редактора.

## 📦 Встановлення

Потрібен **VS Code 1.85.0 або новіший**.

1. Отримайте збірку `editor-toolbar-*.vsix` або [зіберіть її з вихідного коду](CONTRIBUTING.md#build-a-vsix).
2. У VS Code відкрийте **Розширення / Extensions** та меню **…**.
3. Виберіть **Install from VSIX…**, вкажіть файл і відкрийте текстовий документ.

У рядку стану кнопки закладок, форматування, коментування й налаштувань
відокремлені від сусідніх елементів одним вертикальним розділювачем зліва.
У заголовку редактора — список функцій і кнопки згортання/розгортання.
Коли активного текстового редактора немає, кнопки рядка стану приховані.

## 🚀 Перша хвилина роботи

1. **Позначте два місця.** Поставте курсор на рядок і натисніть кнопку закладки.
   Повторіть на іншому рядку. Ліворуч від коду з’являться кольорові позначки.
2. **Переміщуйтеся між ними.** Натисніть наступну або попередню закладку.
   Після останньої закладки перехід починається з першої в поточному файлі.
3. **Знайдіть функцію.** Відкрийте **Функції та процедури**, введіть частину назви
   й виберіть результат. Потрібна група редактора стане активною, блок розгорнеться,
   а рядок коротко підсвітиться.
4. **Упорядкуйте вигляд.** Згорніть або розгорніть файл кнопками в заголовку.
   Для форматування й коментування скористайтеся кнопками в рядку стану.

Для знайомства є [демонстраційний файл](docs/demo/order-service.js) та
[покроковий сценарій](docs/demo/README.md).

## ⌨️ Стандартні комбінації клавіш

Комбінації працюють, коли фокус знаходиться в текстовому редакторі.
Змінити їх можна через **Preferences: Open Keyboard Shortcuts**.

| Команда | Комбінація |
| --- | --- |
| Встановити/зняти закладку | `Ctrl+F2` |
| Наступна закладка | `Ctrl+Shift+F2` |
| Попередня закладка | `Shift+F2` |
| Список закладок поточного файлу | `Ctrl+Alt+F2` |
| Функції та процедури | `Ctrl+Alt+O` |

На macOS `Ctrl` означає **Control**, а не Command. Для функціональних клавіш може
знадобитися `Fn`. Розширення залишає `F2` стандартній команді перейменування символу
VS Code. Форматування, коментування та згортання використовують власні комбінації
VS Code, які залежать від ОС і ваших налаштувань.

[Ідентифікатори команд і приклад перепризначення →](docs/commands.md)

## 🔍 Навігація функціями

Список має групи **Процедури**, **Функції**, **Методи** та **Власні**. Порожні групи
не показуються. Можна шукати за назвою чи описом та перемикати сортування між
порядком у файлі й абеткою всередині кожної групи.

Спочатку розширення використовує символи від мовного провайдера VS Code. Якщо той
не повернув функцій або методів, застосовується резервний парсер. Власні шаблони
можуть додавати результати. Для складного синтаксису найточніший результат дає
розширення відповідної мови. [Підтримувані форми та обмеження →](docs/settings.md#language-support)

## 🔖 Як зберігаються закладки

Закладки належать поточному файлу й зберігаються у стані робочого простору VS Code.
Вони переміщуються після редагувань, зокрема у фонових документах, і зберігаються
під час перейменування файлів або папок через VS Code.

Закладка прив’язана до початку рядка. Якщо багаторядкове видалення поглинає цю
позицію, закладка видаляється; undo не створює її заново. Зміни, внесені під час
закритого VS Code, відстежити неможливо. Після зовнішнього переписування файлу
перевірте позиції; збережені номери за межами документа відкидаються.

## 🎨 Налаштування

Наприклад, змініть колір у налаштуваннях користувача, робочого простору або папки:

```json
{
  "editorToolbar.bookmarkColor": "#8b5cf6"
}
```

Колір оновлюється одразу. Підтримуються `#rgb`, `#rgba`, `#rrggbb` та `#rrggbbaa`.
Назви кольорів на кшталт `orange` не підтримуються.

Для власних оголошень функцій використовуйте `editorToolbar.customPatterns`.
Перша група захоплення в регулярному виразі визначає назву символу.
[Приклад і обмеження →](docs/settings.md#custom-function-patterns)

Написи інтерфейсу підтримують **українську, англійську та російську** й залежать від
мови VS Code. Кнопки заголовка також доступні для незбережених і віддалених текстових
документів. Окремої браузерної версії розширення немає.

## 🩺 Якщо щось не працює

| Симптом | Що перевірити |
| --- | --- |
| Кнопок не видно | Відкрийте текстовий документ і перевірте, що розширення ввімкнене. |
| Комбінація не спрацьовує | Перевірте фокус редактора та конфлікти в Keyboard Shortcuts. |
| Форматування нічого не змінює | Встановіть або виберіть форматер відповідної мови. |
| Функції немає у списку | Перевірте режим мови документа та мовне розширення; резервний парсер приблизний. |
| Пошук функцій зупинився | Перевірте власні шаблони або спробуйте менший файл. |
| Список закрився під час редагування | Відкрийте його знову: попередні номери рядків могли застаріти. |
| Колір відрізняється від очікуваного | Перевірте налаштування папки та правильність hex-кольору. |
